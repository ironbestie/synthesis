## Выборка

Исходные записи и ссылки взяты из архива первой лабораторной. Для каждой модели используется 125 текстов из пяти категорий и 175 текстов с повторами. Каждое из 25 базовых слов или выражений повторяется 1, 2, 4, 8, 16, 32 или 64 раза. Разделитель между повторениями: запятая и пробел. В общем сравнении 150 текстов на модель, по 25 на категорию, включая только k = 8 для повторов. Исходный текст, базовая единица, категория и ссылка сохраняются в texts.csv.

## Распознавание и сравнение

Для всех шести серий используется omniASR_CTC_300M_v2. Загрузка для Transformers: aadel4/omniASR-CTC-300M-v2. Автор конвертации сообщает о сравнении логитов с оригиналом fairseq2 с допуском 0,0001 на контрольном примере. Один декодер greedy CTC без языковой модели и подсказки языка. Многоканальная запись усредняется, затем scipy.signal.resample_poly приводит её к 16 кГц. Аудио дольше 30 секунд обрабатывается последовательными блоками по 30 секунд. На стыке блоков возможно разделение слова. Исходные WAV сохраняются полностью.

Нормализация у исходного текста и гипотезы общая: NFC, нижний регистр, запись цифр словами на соответствующем языке, замена пунктуации пробелами, свёртка пробелов. Для WER слова выделяются по пробелам. В CER входят и пробелы между словами. Числа в исходных текстах записаны словами. CER и WER равны расстоянию Левенштейна, делённому на число символов или слов эталона. В micro складываются числители и знаменатели, macro даёт каждому успешному примеру одинаковый вес. При пустом распознавании все символы и слова эталона считаются пропущенными. Ошибки вызова TTS или ASR вынесены в отдельные статусы, с пустыми метриками и заполненной причиной. Доля совпадений рассчитана среди успешных распознаваний.

## Фонемы и признаки

Phonemizer с eSpeak NG, языки id и be, без ударения. Перед G2P знаки препинания заменяются пробелами. Пробел разделяет фонемы, вертикальная черта обозначает границу слова. Аффрикаты и дифтонги считаются по выданным токенам. Частоты соответствуют текстовым транскрипциям G2P. Повторность слов равна 1 минус отношение числа разных слов к общему числу слов. Аналогично считается доля повторных соседних пар фонем внутри слов. Цепочки согласных обрываются на границе слова. Для CER и WER рассчитывается корреляция Спирмена с каждым признаком отдельно по языку и модели на основной выборке. Для k используются все 175 вариантов повторов. Это описательные связи, включая влияние категории, длины и общих базовых слов.

## Воспроизведение

Запускайте команды из корня распакованной лабораторной. texts.csv и фонемы уже входят в набор. Для пересборки входов передайте в code/prepare.py путь к исходному архиву первой лабораторной.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python code/download_models.py mms supertonic silero asr omni
.venv/bin/python code/g2p.py
.venv/bin/python code/synthesis.py indonesian mms
.venv/bin/python code/synthesis.py indonesian supertonic
.venv/bin/python code/synthesis.py belarusian silero
.venv/bin/python code/align_reference.py
```

Три удалённые серии выполнялись на Tesla T4 в Colab: Python 3.13.16, torch и torchaudio 2.11.0+cu130, NumPy 2.4.6 и soundfile 0.14.0. У OmniVoice версия transformers 5.22.0, у OuteTTS 4.52.3. Для воспроизведения создайте две отдельные среды и установите code/requirements-omni.txt и code/requirements-oute.txt соответственно. В среде OmniVoice запустите code/synthesis.py с аргументами indonesian omnivoice и belarusian omnivoice. Для OuteTTS выполните code/oute_hf.py в чистой папке эксперимента без GGUF в models/outegg. Обе модели используют сохранённые референсы. Точные ревизии MMS, Supertonic, OmniVoice, OuteTTS, DAC и ASR указаны в PINS в code/download_models.py. Для Silero проверяется SHA-256.

```bash
for folder in indonesian/mms indonesian/supertonic indonesian/omnivoice belarusian/silero belarusian/outetts belarusian/omnivoice; do
    .venv/bin/python code/recognize.py "$folder"
done
.venv/bin/python code/analyze.py
.venv/bin/python code/listening.py
```

Скрипты продолжают прерванный запуск по идентификаторам в synthesis.csv и results.csv. Для независимого запуска используйте новую копию данных только с texts.csv, phonemes.csv и references/ по каждой модели. Файлы audio/ содержат монофонический PCM WAV. results.csv связывает запись с исходным текстом, моделью, длительностью, статусом и оценками. В summary.csv доли и расстояния приведены в единицах, в рисунках ошибки показаны в процентах. В figures/ находятся графики по каждому языку, признаки примеров, частоты фонем и коэффициенты корреляции.
